# Set 4 b-roll picks (real, licence-logged)

All files were downloaded with `vs fetch get … --project rootout-set4`; licences are in
`video-studio/projects/rootout-set4/assets/credits.json` / `CREDITS.md` (run `vs credits --project rootout-set4` before delivery).
Keyless providers only (Wikimedia Commons, Openverse/Flickr, Internet Archive). Every file was looked at.
Commons originals were rate-limited (HTTP 429), so several came down as Commons' own 1280/1920 px thumbnails of the same file (same licence).
CC BY / BY-SA = credit line in the post/description. BY-SA: the modified photo is a derivative, so the credit should say the licence (CC BY-SA x.0) and link it.

**Big picture:** the keyless sources have almost no modern *video* for these beats. Only one real video clip was usable
(1947 dandelion digging). Everything else is photos (Ken Burns / punch-in). Video gaps are listed at the end.
