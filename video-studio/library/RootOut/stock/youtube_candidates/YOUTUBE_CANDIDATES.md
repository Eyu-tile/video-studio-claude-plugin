# RootOut YouTube candidates (Creative Commons, not downloaded yet)

YouTube blocks downloads from the cloud server this library was built on (403 / "confirm you are not a bot"), so these are
**looked at, graded and logged, but not downloaded**. Each was judged from 4 frames (thumbnail + YouTube's 25/50/75% frames):
`strips/<id>.jpg` (not committed). Re-check the full clip after download.

Grades: **A** clean b-roll · **B** a usable part, see note · **C** reject · **BANNED** competitor brand on screen.

## Download (on a computer where YouTube works)
```bash
cd video-studio/library/RootOut/stock
vs fetch get youtube_candidates/youtube_candidates.json 8 9 10 11 12 13 14 15 18 19 20 29 42 43 45 46 50 52 54 55 56 57 58 59 61 64 65 70 73 --quality hd --to assets/video
vs learn source RootOut assets/video && vs learn scan RootOut && vs learn sample RootOut   # then describe + atlas
```
Licences are logged in `assets/credits.json` as each file lands. YouTube CC BY needs a credit line (author + link).
The CC flag is set by the uploader: for "free stock footage" re-uploads (Y52–Y59) confirm the original source before a paid ad.
