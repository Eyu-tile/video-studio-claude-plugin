# Lessons: HavenSpool

Learned from feedback. Apply before planning; `vs qa --brand` checks the ones marked checked.

## audio
- [L4] Voice matches the reference (gender, age, accent); listen to the whole VO for pronunciation: numbers, years, HAY-vin & SPOOL, riss-in-oh-LAY-ik (#386 #297 #422)  (MUST)

## color
- [L2] Must pass as real phone footage: natural light, real skin texture, no studio look; cover long AI talking heads with b-roll under the voice (#227 #291 #357 #370)  (MUST)

## cuts
- [L3] Duplicates: copy the reference's structure, scenes, timing, captions and music; never add the product where the reference has none (#302 #366 #227)  (MUST)
- [L5] Watch every export frame by frame before upload: no blips, tweaks or stray bars (#309 #266)  (MUST)

## framing
- [L1] Product at true size: the 50 ml roll-on sits in a palm. Prompt with a hand holding it and use the Products tab photos; check every product shot against them (#300 #355 #357 #395)  (MUST)

## text
- [L8] Castor seeds whole only; never chewing, crushing or rubbing a raw seed on skin (#457)  (MUST)
- [L6] Apply a strategist's copy change to every hook version, not only the one the note is on (#307 #332)
- [L7] Say the angle keyword in the hook itself (e.g. 'Skin tags freezing kits vs...') (#423)
