# Video Studio library

There is one folder per product. Each folder holds all the learned knowledge for that product: footage atlas, previous ads, winning ads, client do-not-use rules, and style guide.

- `CaptureCards/`: TrueClean CaptureCards (dust-mite card). Start with `CaptureCards/README.md`.
- `RootOut/`: WilloMD RootOut wart, corn & callus oil (learned from the official site). Start with `RootOut/README.md`.
- `Spin360/`: Spin360 luxury pedestal fan. Start with `Spin360/README.md`.
- `assets/`: shared, product-neutral assets (sound-effect packs, etc.) used by every product.

When a new product is learned, create `library/<ProductName>/` with the same layout:
- `01_resources_frameio/`
- `02_previous_ads/`
- `03_winning_ads/`
- `04_do_not_use/`
- `AD_STYLE_GUIDE.md`
- `README.md`
